Abrir o VisuObject

Grátis · sem registo · para o secundário

Programação orientada a objetos. Com diagrama de classes e Java.

Com o VisuObject escreves classes Java num projeto como no Eclipse, e o diagrama de classes UML desenha-se ao lado. Se mudares o diagrama, o código muda. Depois crias objetos, executas o programa e acompanhas tudo no depurador.

Iniciar o VisuObject no navegador Primeiro o básico no VisuStruct

Funciona no navegador em computadores e tablets. Os teus projetos ficam na tua pasta de workspace.

visustruct.org/app/?visuobject

Como funciona

Três passos da classe ao programa a correr

  1. 1

    Desenhar

    Escreve classes em Java ou desenha-as no diagrama de classes. Os dois ficam sempre iguais.

  2. 2

    Criar objetos

    No diagrama de objetos crias objetos, dás-lhes valores e ligas uns aos outros.

  3. 3

    Executar e depurar

    Run executa o teu projeto com Java real. No depurador avanças passo a passo e vês os objetos ao vivo.

Funcionalidades

Tudo para ensinar POO

Diagrama de classes, objetos e Java num só lugar, próximo do Eclipse e do Astah.

Diagrama de classes como no Astah

Desenha classes, interfaces, associação, agregação, composição, herança e realização, e ainda notas.

Projetos como no Eclipse

Package Explorer com projeto, pasta src e pacotes, menu Novo para classes e interfaces.

Inspetor de objetos

Edita classe, atributos e métodos em tabelas. Gera construtor, getters, setters e toString().

Diagrama de objetos

Cria objetos com nomes e valores e vê que objeto aponta para qual.

Java real

Run compila todas as classes com Java real. O resultado aparece na consola, também janelas Swing.

Depurador

Pontos de paragem, passo, entrar e sair. Pilha de chamadas e variáveis sempre à vista.

Inspetor de objetos

Editar classes sem escrever cada linha

Clica numa classe no diagrama. No inspetor de objetos mudas o nome, a superclasse e as interfaces, acrescentas atributos e métodos e geras construtor, getters e setters. O VisuObject escreve o código Java exatamente no sítio certo.

  • Visibilidade, tipo, static, final e valor inicial para cada atributo
  • Métodos com parâmetros, tipo de retorno e abstract
  • Sugestões depois do ponto para as tuas próprias classes
  • O VisuObject reconhece sozinho as dependências «create» e «use»

Política de privacidade – utilização do VisuStruct

Compatível com o RGPD: o VisuStruct não recolhe nem guarda dados pessoais. Os seus estrutogramas e ficheiros .visustruct ficam sob o seu controlo — decide se os mantém apenas no dispositivo ou se faz uma cópia de segurança (por exemplo) na sua própria nuvem.

Se utilizar serviços ligados à aplicação (p. ex. App Store, GitHub), aplicam-se as políticas de privacidade desses fornecedores; eles podem aí processar dados. Este sítio é disponibilizado a partir de um servidor; geram-se, como é habitual, dados técnicos de registo do servidor.
