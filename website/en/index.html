VisuStruct — Visual Structogram Editor

Visual structogram editor for Nassi-Shneiderman diagrams — plan algorithms by structure, not syntax first.

With VisuStruct, you develop algorithms as structograms: you break a problem into clear steps (sequence, branching, loops) and can quickly see whether the logic makes sense — great for practice and teaching.

VisuStruct is available as a native SwiftUI app for iPad and Apple silicon Mac, and as a Java app for Windows/macOS/Linux. Both share the same .visustruct file format, so you can start on an iPad and continue on a computer (or the other way around).

SwiftUI app for iPad & Mac

VisuStruct is available as a native SwiftUI app for iPad and Mac with Apple silicon (App Store).

Java app for Windows, macOS & Linux

For the desktop: build your structogram via drag & drop from the palette, rearrange steps, and export results (e.g. as PNG). You need a Java Runtime Environment (JRE), e.g. Eclipse Temurin from Adoptium.

Key features

  • Simple, intuitive interface — the focus stays on logic, not punctuation.
  • Develop the algorithm as structure first, then translate it into code more easily.
  • One shared format: .visustruct on the desktop (Java) and on iPad & Mac (SwiftUI).

Algorithm first, then code

Start with logic and flow — your algorithm. Then express the same structure with syntax, in whatever programming language you choose — step by step and easy to follow.

Privacy policy – use of VisuStruct

Privacy-friendly (GDPR): VisuStruct does not collect or store personal data. Your structograms and .visustruct files stay under your control — you decide whether to keep them on your device or back them up (for example) in your own cloud.
