VisuStruct — Visual Structogram Editor

Visual structogram editor for Nassi-Shneiderman diagrams — plan algorithms by structure, not syntax first.

The open-source Java desktop app and the SwiftUI app for iPad and Mac with Apple silicon share one .visustruct format. Drag-and-drop editing, clean UI, three interface languages: English, German, Portuguese.

Java app — Windows, macOS & Linux

Java desktop: palette, tabbed canvas, export (e.g. PNG). Needs a Java runtime.

SwiftUI app — iPad & Mac

SwiftUI for iPad and Apple silicon Mac — palette, canvas, inspector; same .visustruct as Java.

Key features

  • Drag-and-drop Nassi-Shneiderman structograms
  • See control flow and logic before you commit to code
  • Minimal, focused interface
  • For teaching, learning, and sketching real algorithms

Why VisuStruct?

When syntax comes first, structure gets buried — VisuStruct keeps branches, loops, and decisions visible from the start.

Privacy policy – use of VisuStruct

Scope

Applies to the VisuStruct apps (Java desktop, SwiftUI for iPad and Apple silicon Mac) and this static site, offered by Holger Sebastiao: no analytics cookies; no personal data is collected on this site.

Data in the apps

I do not operate servers that receive your diagrams or .visustruct files. Data is stored and processed only locally on your device. Cloud sync (e.g. iCloud, OneDrive) only if you set it up yourself.

I do not collect, analyse, or use your diagram data for advertising or profiling. It is used only inside the app to edit, save, and export.

Account

You do not need an account with me.

App Store, GitHub, and similar services process their own technical or account data under their policies — see each provider.
