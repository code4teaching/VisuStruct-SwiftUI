Object-oriented programming. With class diagrams and Java.

With VisuObject you write Java classes in a project like in Eclipse, and the UML class diagram draws itself alongside. Change the diagram and the code changes. Then create objects, run the program and watch it in the debugger.

How it works

Three steps from a class to a running program

  1. 1

    Draw

    Write classes in Java or draw them in the class diagram. Both always stay the same.

  2. 2

    Create objects

    In the object diagram you create objects, give them values and connect them.

  3. 3

    Run and debug

    Run executes your project with real Java. In the debugger you go step by step and see the objects live.

Features

Everything for teaching OOP

Class diagram, objects and Java in one place, close to Eclipse and Astah.

Class diagram like Astah

Draw classes, interfaces, association, aggregation, composition, inheritance and realization, plus notes.

Projects like Eclipse

Package Explorer with project, src folder and packages, a New menu for classes and interfaces.

Object inspector

Edit class, attributes and methods in tables. Generate a constructor, getters, setters and toString().

Object diagram

Create objects with names and values and see which object points to which.

Real Java

Run compiles all classes with real Java. Output appears in the console, Swing windows too.

Debugger

Set breakpoints, step over, into and out. Call stack and variables always in view.

Object inspector

Edit classes without typing every line

Click a class in the diagram. In the object inspector you change its name, superclass and interfaces, add attributes and methods and generate a constructor, getters and setters. VisuObject writes the Java code exactly where it belongs.

  • Visibility, type, static, final and initial value for every attribute
  • Methods with parameters, return type and abstract
  • Suggestions after the dot for your own classes
  • VisuObject detects «create» and «use» dependencies by itself

Privacy policy – use of VisuStruct

Privacy-friendly (GDPR): VisuStruct does not collect or store personal data. Your structograms and .visustruct files stay under your control — you decide whether to keep them on your device or back them up (for example) in your own cloud.

If you use linked services related to the app (e.g. App Store, GitHub), the privacy terms of those providers apply; they may process data there. This website is served from a server; as usual, technical server log data is generated.
