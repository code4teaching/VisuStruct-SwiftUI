# SwiftUI-Prototyp (Legacy)

Diese Dateien sind ein **älterer Prototyp** ohne das fertige Xcode-Projekt unter `VisuStructXcodeOpen/`.

Für die aktuelle App: **`VisuStructXcodeOpen/VisuStruct.xcodeproj`** öffnen.

Wenn du nur **VisuStructCore** testen willst:

1. Neues iOS-App-Projekt in Xcode anlegen.
2. **`VisuStruct-iOS/VisuStructCore`** als **lokales Swift Package** einbinden (File → Add Package Dependencies… → Add Local…).
3. Optional: die `ContentView.swift` aus diesem Ordner nur noch zu Referenzzwecken nutzen — die Produktiv-UI liegt im Xcode-Projekt.
