# SwiftUI prototype (legacy)

Older prototype **without** the production Xcode project under `VisuStructXcodeOpen/`.

**Current app:** open **`VisuStructXcodeOpen/VisuStruct.xcodeproj`**.

To try **`VisuStructCore`** only:

1. Create a new iOS app project in Xcode.
2. Add **`VisuStruct-iOS/VisuStructCore`** as a **local Swift package** (File → Add Package Dependencies… → Add Local…).
3. Optional: use `ContentView.swift` here **for reference only** — production UI lives in the Xcode project.
