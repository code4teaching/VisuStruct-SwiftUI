Lessons are about trying things out: step 1 „Das schaffst du heute“, a few hands-on exercises, a game, and „Das hab ich geschafft“ as the checklist; no knowledge test. First lessons (German): 1 „Losfahren“ (drive, change numbers, turn), 2 „Immer wieder“ (square, „wiederhole“, triangle and other shapes), 3 „Der mBot2 misst“ (show the distance, drive while the way is free) and 4 „Entscheidungen“ (wenn/sonst with the wall and the colour sensor). In „Wo landet der mBot2?“ the rounds are shown as blocks instead of Java (`blockPicture.ts`). Tests in `blockLessons.test.ts`.
- **Web 0.15.25, VisuBot blocks (stage 5): variables and operators:** new areas in „Elemente“ (VisuBot): **Operatoren** (plus, minus, mal, geteilt durch, Rest beim Teilen, Zufallszahl, kleiner als, größer als, gleich, und, oder, nicht; round = number, hexagonal = yes/no, green), **Variablen** (Variable anlegen → `int zahl = 0` with a free name, setze Variable auf → `zahl = 0`, ändere Variable um → `zahl = zahl + 1`; every declared variable appears as an orange building block) and **Steuerung** („wiederhole 10 mal“ → `for (int i = 0; i < 10; i++)`). In the blocks, operators and variables are dropped onto a white field (an operator gets brackets only when needed) or onto a condition (replaces it; „und“/„oder“/„nicht“ combine with the old condition). Variables show as orange pills; the one being declared or set is not a field. „Zufallszahl von [1] bis [10]“ is a green pill with two fields (`(int) (Math.random() * 10) + 1`). A count loop whose variable is not used in its body reads „wiederhole [10] mal“; its end can also be a variable. Commands from „Elemente“ with empty brackets (`mbot.forward()`) get an empty white field to type the number. The rules come from VisuBlocks (`expressions.ts`, `variables.ts`). Tests in `blockView.test.ts`.
- **Web 0.15.24, descriptions brought up to date:** lesson „Der Editor“ (de/en/pt) explains editing text by double-click/double-tap right in the structure chart (Enter takes it, Esc cancels, keyboard: select and Enter) and the grip line that changes the object inspector's height; VisuBot lesson „Struktogramm und Editor“ (de/en) adds both plus a hint on the button „Blöcke“ (Scratch-like blocks, same program, switch any time), with the new pointer `#zeige-bloecke` (termTips.ts). - **Web 0.15.23, VisuBot blocks: counting loop for kids:** in the block view a simple `for` loop reads „zähle mit i von [0] bis unter [10] in Schritten von [1]“ (en „count with i from 0 to below 10 by 1“). Only numbers are typed into the white fields (the end can also be a sensor); the Java head is written automatically, e.g. start 0 → `int i = 0`, step 2 → `i += 2`; counting down (`i > 0; i--`) reads „bis über“. A new `for` loop dragged into the blocks starts as `for (int i = 0; i < 10; i++)`, nested loops count with j, k … Other heads (e.g. `i < anzahl`) stay text. The rule comes from the new shared block library VisuBlocks (`code4teaching/visublocks` on GitHub, by Christian Klein and Holger Sebastiao, MIT), included as package `visublocks` at a fixed commit; it is planned for all VisuCode projects. Tests in `countLoop.test.ts`.
- **Web 0.15.22, edit text right in the structure chart:** in VisuStruct and the VisuBot box view a double-click or double-tap on an element opens an input field over its text (statement, condition of if/while/do-while, switch expression, call, break); the for loop gets three small fields (start; condition; step) and a double-tap on a case label edits the case name.
