Termos técnicos da área de aprendizagem. Quando um termo aparece num passo, fica marcado uma vez e mostra a sua
explicação ao passar o rato ou ao tocar. Se estiver a negrito nesse passo, é explicado ali mesmo e não é marcado.
`auch:` indica outras formas que também são reconhecidas. Maiúsculas e minúsculas contam.

### Algoritmo
auch: algoritmo, algoritmos, Algoritmos
Instruções exatas, passo a passo, para resolver uma tarefa. Cada passo é claro.

### Estrutograma
auch: estrutograma, estrutogramas, Estrutogramas, diagrama de Nassi-Shneiderman, diagramas de Nassi-Shneiderman, diagrama estruturado
Um algoritmo desenhado como imagem feita de blocos. Lê-se de cima para baixo. Também se chama diagrama de Nassi-Shneiderman.

### Fluxograma
auch: fluxograma, fluxogramas, Fluxogramas
Um algoritmo desenhado com símbolos ligados por setas (DIN 66001 / ISO 5807). Um losango é uma decisão.

### Pseudocódigo
auch: pseudocódigo
Um algoritmo escrito como texto em linguagem corrente com palavras fixas como SE e ENQUANTO. A indentação mostra o que pertence ao quê.

### Instrução
auch: instrução, instruções, Instruções
Um único passo no estrutograma, por exemplo um cálculo, uma entrada ou uma saída.

### Sequência
auch: sequência, sequências, Sequências
Passos que são executados uns a seguir aos outros, de cima para baixo, cada um exatamente uma vez.

### Decisão
auch: decisão, decisões, Decisões, instrução condicional, instruções condicionais, estrutura de decisão
Um bloco que usa uma condição para decidir qual de dois ramos é executado. Também se chama instrução condicional.

### Ramo
auch: ramo, ramos
Um dos dois caminhos de uma decisão: à esquerda para verdadeiro (true), à direita para falso (false).

### Ciclo
auch: ciclo, ciclos, Ciclos, repetição, estrutura de repetição
Um bloco que repete passos enquanto uma condição se verificar.

### Corpo do ciclo
auch: corpo do ciclo
O interior de um ciclo, ou seja, os passos que são repetidos.

### Iteração
auch: iteração, iterações
Executar uma vez o interior de um ciclo.

### Condição
auch: condição, condições, Condições
Uma pergunta que só pode ter como resposta sim (true) ou não (false), por exemplo idade >= 18.

### Marcador
auch: marcador, marcadores
Um bloco vazio com o sinal ø. Se arrastares um elemento para cima dele, o elemento substitui-o.

### Inspetor de objetos
A área por baixo do diagrama. Aqui editas o texto e as definições do bloco em que acabaste de clicar.

### Simulação
auch: simulação
Executa o teu estrutograma no editor, se quiseres passo a passo. Assim vês o que acontece.

### Variável
auch: variável, variáveis, Variáveis
Uma caixa com etiqueta para um valor. Tem um nome, um tipo de dados e um valor.

### camelCase
auch: CamelCase
Forma de escrever nomes com várias palavras: escritas juntas, cada palavra seguinte começa com maiúscula, p. ex. `precoComIva`.

### Constante
auch: constante, constantes, Constantes
Uma variável cujo valor não muda depois de definido. Escreve-se `const` à frente, p. ex. `const double IVA = 0.23`.

### Tipo de dados
auch: tipo de dados, tipos de dados, Tipos de dados
Diz que tipo de valor cabe numa variável: int (número inteiro), double (número decimal), String (texto), boolean (verdadeiro ou falso) ou char (um único caractere).

### Atribuição
auch: atribuição, atribuições, Atribuições
O sinal =. Calcula o lado direito e guarda o resultado na variável à esquerda.

### Variável auxiliar
auch: variável auxiliar, variáveis auxiliares
Uma variável extra que guarda um valor durante pouco tempo, por exemplo ao trocar valores.

### Modelo EPS
auch: entrada-processamento-saída
Entrada, processamento, saída: primeiro pedir os valores, depois calcular, depois mostrar o resultado.

### Análise do problema
auch: análise do problema
Lês uma tarefa com atenção e descobres o que é dado, o que procuras e como chegar de um ao outro.

### Operador de comparação
auch: operador de comparação, operadores de comparação, Operadores de comparação
Um sinal que compara dois valores, por exemplo == ou <. O resultado é true ou false.

### Seleção
auch: seleção, seleção múltipla, escolha múltipla
Um bloco que executa exatamente um de vários casos, consoante o valor de uma variável. Também se chama seleção múltipla.

### Ciclo pré-teste
auch: ciclo pré-teste, ciclos pré-teste, controlado no início
O ciclo verifica a sua condição antes de cada iteração. Se a condição for falsa logo no início, o ciclo não é executado nem uma vez.

### Ciclo pós-teste
auch: ciclo pós-teste, ciclos pós-teste, controlado no fim
O ciclo só verifica a sua condição depois de cada iteração. Por isso é sempre executado pelo menos uma vez.

### Variável contadora
auch: variável contadora, variáveis contadoras, contador
Uma variável que vai contando num ciclo, normalmente i.

### Ciclo infinito
auch: ciclo infinito, ciclos infinitos, ciclo sem fim
Um ciclo cuja condição nunca se torna falsa. Nunca para sozinho.

### Array
auch: array, arrays, Arrays, vetor, vetores
Uma fila de posições com um nome comum e o mesmo tipo de dados.

### Índice
auch: índice, índices
O número de uma posição num array. Começa-se a contar em 0.

### char
O tipo de dados para um único caractere. Fica entre aspas simples, p. ex. 'C'. Já "C" com aspas duplas é uma String.

### Código de caractere
auch: código de caractere, códigos de caractere, código ASCII, tabela ASCII
O número que está por trás de um caractere. Na tabela ASCII, o A tem o código 65, o B 66 e assim por diante. Em Java, (int) transforma um caractere no seu código e (char) transforma um código no caractere.

### String
auch: strings, Strings, cadeia de caracteres, cadeias de caracteres
Um texto, ou seja, uma fila de caracteres. Em Java o tipo de dados chama-se String. Os caracteres contam-se a partir de 0.

### Array 2D
auch: arrays 2D, array bidimensional, arrays bidimensionais, matriz, matrizes
Um array com linhas e colunas, como uma tabela. Uma posição precisa de dois índices, p. ex. `lugares[1][2]`.

### Subprograma
auch: subprograma, subprogramas, Subprogramas, método, métodos, Métodos, procedimento, procedimentos, função, funções, Funções
Um estrutograma próprio para uma parte da tarefa. É executado quando é chamado. Em Java chama-se método; consoante o tipo, também procedimento ou função.

### Parâmetro
auch: parâmetro, parâmetros, Parâmetros
Uma variável na linha de cabeçalho de um subprograma. Quando é chamado, recebe o valor que está entre parênteses.

### Código esparguete
auch: código esparguete
Um programa que salta de um lado para o outro de forma tão confusa que mal se consegue seguir o que acontece. Os estrutogramas evitam isso.

### Passagem por valor
auch: passagem por valor
Um subprograma recebe uma cópia do valor. Se alterar o seu parâmetro, a variável de quem chamou fica igual.

### Passagem por referência
auch: passagem por referência
Um subprograma recebe uma referência para os mesmos dados, p. ex. para um array. Se alterar uma posição, quem chamou também vê a alteração.

### Valor de retorno
auch: valor de retorno, valores de retorno, Valores de retorno
O resultado que um subprograma devolve à chamada com return.

### Interrupção
Um bloco que sai imediatamente do ciclo em que está. Depois o programa continua por baixo do ciclo.

### Erro de sintaxe
auch: erro de sintaxe, erros de sintaxe, Erros de sintaxe
Um erro na forma como o código está escrito, por exemplo um `;` em falta. O programa nem sequer arranca. Em inglês: syntax error.

### Erro de execução
auch: erro de execução, erros de execução, Erros de execução
Um erro que só acontece enquanto o programa corre, por exemplo dividir por 0. O programa para nesse ponto. Em inglês: runtime error.

### Erro de lógica
auch: erro de lógica, erros de lógica, Erros de lógica
O programa corre sem nenhuma mensagem, mas dá um resultado errado. Encontra-se com o teste de secretária. Em inglês: logic error.

### Teste de secretária
auch: teste de secretária, testes de secretária, Testes de secretária, teste de mesa
Executas um estrutograma no papel e anotas os valores das variáveis depois de cada passo.

### Pesquisa linear
auch: pesquisa linear
Uma forma de pesquisar que compara todos os valores, um a seguir ao outro, com o valor procurado. Também funciona com valores desordenados.

### Pesquisa binária
auch: pesquisa binária
Uma forma de pesquisar em valores ordenados. Olha para o meio e continua a pesquisar só na metade certa.

### Bubble sort
auch: bubble sort, Bubblesort, ordenação por bolha
Uma forma simples de ordenar. Compara sempre dois vizinhos e troca-os se estiverem na ordem errada.

### Evento
auch: evento, eventos, Eventos
Algo que uma pessoa faz num programa com janelas, por exemplo clicar num botão. O programa reage com um ouvinte (ActionListener).

### Interface
auch: Interfaces
Uma espécie de contrato em Java: diz que métodos uma classe tem de ter. `ActionListener` é uma interface com o método `actionPerformed`.

### Exceção
auch: exceção, exceções, Exceções, Exception, Exceptions
Um erro que só acontece durante a execução, por exemplo um índice fora do array. Se nenhum `catch` a apanhar, o programa termina.

### Atributo
auch: atributo, atributos, Atributos
Uma variável que está diretamente na classe e não dentro de um método. Com `static` pertence à própria classe e vive tanto tempo como o programa, por exemplo um contador de cliques que vários ouvintes alteram.

### Scanner
Um bloco pronto do Java que lê entradas do teclado, por exemplo um número com `scanner.nextInt()`. Precisa de `import java.util.Scanner;` mesmo no início.

### Comentário
auch: Comentários, comentário, comentários
Uma nota no código para pessoas. O Java salta-a ao executar. `//` vale até ao fim da linha, `/* … */` pode ocupar várias linhas.

### import
Uma linha mesmo no início do código Java que vai buscar um bloco pronto a um pacote, por exemplo `import java.util.Scanner;`. Sem ela, o Java não conhece o nome.

### código-fonte
auch: Código-fonte
O texto do programa que as pessoas escrevem e leem, por exemplo num ficheiro `Tabuada.java`.

### compilador
auch: Compilador, compiladores
Um programa que traduz código-fonte. Em Java chama-se `javac` e transforma um ficheiro `.java` em bytecode num ficheiro `.class`.

### bytecode
auch: Bytecode
A forma traduzida de um programa Java num ficheiro `.class`. Quem o lê é a JVM, não as pessoas.

### JVM
auch: Java Virtual Machine, máquina virtual
A Java Virtual Machine executa bytecode. É um programa que funciona como um pequeno computador feito de software no Windows, no macOS ou no Linux. Por isso o Java é independente da plataforma.

### JRE
Java Runtime Environment: a JVM e blocos prontos. Com ele podes executar programas Java, mas não compilá-los.

### JDK
Java Development Kit: o JRE e ainda o compilador `javac` e outras ferramentas. É preciso para programar.

### independente da plataforma
Um programa corre sem alterações em sistemas operativos diferentes. Em Java é a JVM que o permite: “Write once, run anywhere”.

### código máquina
auch: Código máquina
Instruções em forma de números que o processador executa diretamente. Cada tipo de processador tem o seu próprio código máquina.

### compilador JIT
auch: JIT
Uma parte da JVM que, durante a execução (“just in time”), traduz o bytecode muito usado em código máquina. Assim o Java fica mais rápido.
