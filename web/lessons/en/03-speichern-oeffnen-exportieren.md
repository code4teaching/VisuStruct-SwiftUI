## The .visustruct file

Structure charts are saved as **.visustruct** files. All versions of VisuStruct use the same format: in the browser, on Mac, iPad and iPhone, and the Java app on the computer. So you can start in the browser at school and carry on in the app at home.

## Save and open

- **[Save](#zeige-speichern)** (Ctrl+S): The diagram is saved as a file. If the **Files** column is set up (see below), it goes there. Otherwise the browser asks where to put it or puts the file in your downloads folder.
- **[Open](#zeige-oeffnen)** (Ctrl+O): Load a saved file again. You can also simply drag a file into the browser window.

> The browser remembers your exercises automatically. But that only works in this browser on this device. So always save important work as a file as well.

## The Files column

To the left of the learning area you find the [📁 Files](#zeige-dateien) column. There you keep all your programs in one place, your **workspace**.

1. Open the column and set up the workspace. In Chrome and Edge you choose a folder on your computer for it, for example in your documents. On the iPad and in other browsers, VisuStruct saves in the browser.
2. Use the folder icon with **+** to create a folder for your class, for example `11FI1`. Clicking a class folder makes it the current **class**.
3. Save as usual. In your class, VisuStruct automatically creates a folder with today's date, for example `2026-10-23`, and saves the program in it. The file name comes from the title.

Clicking a program in the column opens it again. That way you quickly find every lesson later.

Your **learning progress** goes into the workspace too: the file `lernstand.json` lists the lessons and exercises you have finished. If you open the workspace in another browser, your progress is back.

> Browser storage only stays in this browser on this device. A real folder on your computer is safer, because you can also back it up and pass it on.

## Several diagrams in tabs

Above the structure chart you see the [tabs](#zeige-reiter). With **+** or [New](#zeige-neu) you open another, empty diagram. A dot • in front of the name shows that there are unsaved changes.

You type the [title](#zeige-titel) of a diagram into the field above the structure chart. It also appears when you export and is suggested as the file name.

## Share as an image or PDF

With [Export](#zeige-exportieren) in the tools (icon with an arrow pointing up) you can share your structure chart:

- **Image (PNG):** to put into a worksheet or a presentation
- **Vector graphic (SVG):** stays sharp at any size
- **PDF (A4):** one page to hand in or print
- **Print** (Ctrl+P): straight to the printer

Under the [gear](#zeige-textgroesse) at the top right, Text size sets the font size. Larger text also shows when you export an image.
