# VisuBlocks

Gemeinsame Block-Regeln für die VisuCode-Projekte (VisuBot, VisuMicro …): was ein Kind auf einem Block sieht, welche Felder es ausfüllt und welcher Java-Code daraus entsteht. Kinder tippen nur Werte, das Java schreibt der Block.

Entwickelt von Christian Klein und Holger Sebastiao. MIT-Lizenz.

Das Original kommt ins Repo `code4teaching/visublocks` (GitHub, gespiegelt nach GitLab); bis dahin liegt es hier. Die Dateien kennen kein DOM.

- `countLoop.ts`: Zählschleife „zähle mit i von [0] bis unter [10] in Schritten von [1]“ ↔ `for (int i = 0; i < 10; i++)`
